## B03 invitation and activation

Use WorkOS AuthKit **staging** for a disposable invitation flow. The admin form accepts email only. Keep Verity's installation entitlement and signed offline interval in SwarmTracker storage, separate from AuthKit identity.

1. Issue an application invitation for the exact email. Associate invitation ID, target email, expiry, and local pending activation ID. WorkOS documents both application-wide and organization invitations; choose application-wide unless an organization is explicitly created.
2. At acceptance, bind the returned verified user email and invitation ID to the pending record, collect required Name and visible optional Organization in Verity, then issue the installation entitlement. Do not treat entering an email or opening the link as activation.
3. Test wrong recipient, reused/expired invitation, relaunch, offline signed interval, device replacement, and revocation. WorkOS says invitation acceptance shortly after email delivery may itself verify email; otherwise its ordinary verification flow applies. Inspect `email_verified` and events rather than assuming every click has identical treatment.
4. Use staging's separate keys, users and webhooks. Test with example-domain accounts where an email is not meant to be delivered; use a controlled real test inbox only for actual delivery acceptance. No customer invitation is authorized here.

Sources: https://workos.com/docs/authkit/invitations ; https://workos.com/docs/authkit/email-verification ; https://workos.com/docs/authkit/environments ; https://workos.com/docs/reference/authkit/user

## B06 provider sign-in investigation

The Google quickstart uses a desktop client and application default credentials for a testing environment; production needs a deliberate credential design. Do not copy tokens into Verity records or confuse this Console path with Claude.ai subscription delegation. Test local token storage, real request, usage source, logout, stale credentials, and fail-closed dispatch. Sources: https://platform.claude.com/docs/en/cli-sdks-libraries/cli/authentication ; https://platform.claude.com/docs/en/cli-sdks-libraries/cli/scripting
