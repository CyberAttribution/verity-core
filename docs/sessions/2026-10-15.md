## Governance and data boundaries

Telemetry is observational. Manifest identity and task descriptions are integration-reported; receipt times are local. It does not grant authorization, enforce policy on external tools, certify execution or establish evidence truth/completeness. Interrupted work remains visible, and fresh contact is distinct from historical gaps. Hash chains need an independently retained checkpoint to detect wholesale rewriting or truncation.

The ingestion schema excludes prompt/response text, command text, tool arguments, credentials and environment dumps. The harness's explicit developer prompts went to the authorized Scaleway model over SSH; separate private local review output files contain its responses. Telemetry went to a loopback MacBook worker and SQLite. No OpenLIT/cloud telemetry exporter was enabled. Existing per-job cloud-evidence authorization gates were preserved. Product activation is a separate control.

Offline pilot codes are Ed25519-signed, installation-bound and expiring; the CLI defaults to seven days and permits 1–30 days. Imported signed cumulative revocation lists must advance revision. There is no instantaneous offline remote revocation or activation server. Local clock checks are best effort, and local state is not tamper-proof DRM. Only the public issuer key is bundled. The test issuer private key and collector token are excluded from source, exports and this report.
