Upload a file and this node extracts evidence locally — cryptographic hash, container/codec structure, embedded metadata, representative frames, audio track — assembles a structured evidence package, and produces a graded, bounded authenticity assessment saved as a Canonical Case. Fully local: no cloud, no upload leaves this machine, temporary media is deleted after analysis.
