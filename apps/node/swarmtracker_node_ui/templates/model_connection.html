Connect an existing local OpenClaw model

Activation → Choose an agent → model connection → governed request and evidence.

This guided path supports the tested OpenClaw v0 text service. Enter its loopback address and the exact model name it serves. Registration installs nothing, loads no model and sends no specimen. An HTTP health response and a completed governed request are separate checks.

Model name and revision remain operator declarations until supported by separately inspected evidence. No provider passwords or API keys belong in this form.

Then verify the route

  1. Select this connection when registering your agent and choose a declared resource.
  2. Check its connection health in Models & Connections. New agents require a fresh check.
  3. Submit a small non-sensitive governed request. Inspect its outcome, model and runtime event, then export the receipt and retain its checkpoint separately.

Other connection methods

Frontier-provider sign-in, protected API-key storage and external governed requests are not enabled by this local form. Additional connection records remain descriptive registration only. Direct Ollama analysis settings are separate from this OpenClaw adapter; do not point this adapter directly at an Ollama server.
