# October 17 coordinator and focused component evaluations

## Boundary and acceptance

The Sessions SQLite event store remains the read-only observation and export record. The new `session_coordinator.py` owns a separate durable, ordered queue and only dispatches an explicitly authorized, fixed read-only GLM review adapter through a loopback tunnel. It records the request ID and `submitted` transition before HTTP, then the response, usage and finish reason. `stop` plus nonempty content becomes `completed`; a human must separately record source/test evidence for `independently_verified`. `length` becomes `failed`; a transport exception becomes `unresolved`. No arbitrary command or model-generated instruction can execute.

The worker's SQLite `BEGIN IMMEDIATE` transaction serializes claims; an owner heartbeat renews during a request. New ownership turns submitted or acknowledged work into unresolved, never automatic replay. An explicit manual retry requires a failed request with no stored response, concrete no-execution evidence and fewer than two attempts. Pause, permanent stop, dependency verification and the fixed rental ceiling gate dispatch. A paused in-flight response can still be stored. The worker does not offer exactly-once remote execution, authenticate a same-user database, or replace Keel authorization. The review adapter is fixed to `127.0.0.1:18001`, served alias `glm-5.3-flash` for pinned `wtdcode/GLM-5.3-Flash-AWQ-W4A16`; both `reasoning_effort` and `chat_template_kwargs.reasoning_effort` are `low`.

Acceptance: 43 focused tests passed, including two task restart preservation, budget refusal after restart, uncertain submission without replay, truncation, pause, manual retry limit, telemetry outage, and denied/unavailable policy decisions. Live MacBook run persisted two initial HTTP alias errors, reconciled them as failed, then a truncated review (`length`) and a complete review (`stop`). The complete review was independently adjudicated against code and tests. GLM's claim that `length` was accepted is false: `run_one` marks it failed. Its settings-injection claim is blocked by exact settings validation. A subsequent telemetry contract review completed; its synchronous-export concern prompted bounded asynchronous metadata emission. Three further GLM reviews completed: the recovery critique prompted a restart budget test, the OPA critique identified the real policy-hash/server-binding gap, and the GPU critique remained unaccepted because the supplied excerpt ended mid-file and its completion claim conflated process state with verified outcome. Existing Sessions and report-action tests passed alongside the new tests.

## Ordered project decisions

| Project/version examined | License, dependencies and operational fit | Decision |
|---|---|---|
| [LangGraph 1.2.13](https://github.com/langchain-ai/langgraph/releases) | MIT; `langchain-core`, checkpoint, SDK, prebuilt, Pydantic and xxhash in the [package manifest](https://github.com/langchain-ai/langgraph/blob/main/libs/langgraph/pyproject.toml). Local SQLite saver is a [separate package](https://github.com/langchain-ai/langgraph/blob/main/libs/checkpoint-sqlite/README.md). Checkpoints persist graph state; [interrupt/resume](https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/interrupts.mdx) can replay a node and require separate side-effect reconciliation. Its migration and checkpoint owner would duplicate our SQLite authority. No hosted LangSmith needed. | Defer adapter; existing transactional queue is smaller for a fixed worker. |
| [OpenLIT Python SDK 1.45.0](https://github.com/openlit/openlit/blob/main/sdk/python/README.md) | Apache 2.0. The inspected wheel lists OpenAI, Anthropic, boto3 and many OTel instrumentors; isolated install measured **141 MiB**. SDK default content capture is true; the experiment set it false and disabled automatic instrumentors. A synthetic request emitted a metadata-only OTLP span to a local HTTP sink with session/task/request/model, monotonic latency, finish reason and token counts; no secret prompt/response markers appeared. Synthetic `length` and telemetry exception tests leave the task failed or complete according to the model result, never verified. Current [OSS pricing](https://www.openlit.io/pricing) says free self-hosting; [Enterprise](https://www.openlit.io/enterprise) lists RBAC, audit, alerts, scoped keys and GPU cost features. | Defer runtime dependency and dashboard; optional bounded metadata callback meets the narrow need at lower footprint. |
| [DCGM Exporter 4.8.4](https://github.com/NVIDIA/dcgm-exporter/releases) | Apache 2.0, paired DCGM 4.6.1 and Go dependencies. [NVIDIA install guidance](https://docs.nvidia.com/datacenter/dcgm/latest/gpu-telemetry/dcgm-exporter.html) requires compatibility and GPU runtime, and its container example adds `SYS_ADMIN`. On rental driver 580.105.08, `dcgmi` and exporter image were absent. Existing `nvidia-smi` recorded UUID, 0% sample utilization and ~75.5 GiB per A100 at 14:54:14 UTC in Sessions; samples become stale after threshold. No public metrics endpoint. | Defer deployment; no measured incremental benefit justifies service and privileges for these fields. |
| [OPA 1.21.2](https://github.com/open-policy-agent/opa/releases) | Apache 2.0, standalone Go engine with substantial [module dependencies](https://github.com/open-policy-agent/opa/blob/main/go.mod). Isolated adapter accepts explicit boolean decisions from fixed loopback path; missing input, undefined result and evaluator outage deny. The executor test refuses denied/unavailable decisions, and Keel remains a separate required approval. Synthetic evaluator used; actual OPA binary was unavailable, so policy hash identifies supplied bytes but does **not** prove the server loaded them. [OPA API](https://www.openpolicyagent.org/docs/rest-api) can return HTTP 200 without `result`. | Defer live integration pending a versioned policy and real binary test; same-user filesystem bypass remains. |
| [pywebview 6.2.1](https://github.com/r0x0r/pywebview/releases) | BSD 3-Clause; [manifest](https://github.com/r0x0r/pywebview/blob/master/pyproject.toml) brings PyObjC frameworks on macOS, `bottle`, `proxy_tools`, etc. The Swift/AppKit WKWebView shell already wraps the app. | Defer until a concrete cross-platform or packaging gap. |
| [Tauri 2.12.x stable](https://github.com/tauri-apps/tauri/releases) | [MIT or Apache 2.0](https://github.com/tauri-apps/tauri/blob/dev/Cargo.toml); Rust, Wry/Tokio/Serde and platform lifecycle, signing and updater work. Existing Python backend and Swift shell would need migration. | Defer until a specific updater, tray, notification or cross-platform requirement warrants it. |

OpenLIT traces, GPU utilization and OPA decisions are observations or inputs to an enforcement boundary, never proof of accepted model work or provider billing. Token usage has no fixed-rental dollar attribution here. Provider-reported charge remains separate from the boot-proxy estimate.
