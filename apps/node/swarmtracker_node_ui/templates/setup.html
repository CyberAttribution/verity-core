Connection and recovery

If the runtime is unavailable, use Test saved connection above. Check the selected endpoint and model inventory, start or reconnect the independently operated runtime, then test again. A reachable model list only proves endpoint reachability; run a small analysis and inspect its actual response before relying on it.

Application restart preserves the local profile and records. A submitted request whose outcome was not observed must be reconciled from its request ID and output before another dispatch. In Sessions, inspect worker PID, heartbeat, current task, approval and spending gates. Keep any exported history and its SHA-256 checkpoint separately; the package does not itself give a different chat access to this profile.

Quitting the native shell stops only the backend process it launched. It does not stop an independently operated model, rental instance, or supervised session worker.
