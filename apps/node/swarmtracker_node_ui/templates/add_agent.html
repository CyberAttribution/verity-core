Connect the existing OpenClaw pilot

This adapter was tested with the existing local OpenClaw v0 service and its /v0/generate interface. Choose a local model connection whose provider is openclaw; it must point to that service, such as http://127.0.0.1:8090. A remote Mac needs an independently established private tunnel.

If the service is absent, have the administrator restore the tested pilot before registering it. This form does not install a current OpenClaw framework, and compatibility with other OpenClaw versions has not been established.

After registration, check connection health and run a bounded request in Models & Environment. Health alone does not prove a model request completed. Inspect the recorded task, runtime event and result hash afterward.

Verity gates the local text requests it routes. It does not capture arbitrary framework tools, stop direct runtime calls or isolate a process with the same macOS account. Account names, versions and machine details are operator declarations.

Other agents

Google ADK and Muse adapters require separate implementation and acceptance. Instinct requires a supported integration. Use custom registration to record a planned setup; it will not enable these routes.
